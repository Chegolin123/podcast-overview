# Arin — обзор

Превращает статью, PDF или ссылку в подкаст с диалогом двух ведущих и готовый
пост для соцсетей. Локально, без облачных TTS-подписок.

Приватный репозиторий: `Chegolin123/podcast` — доступ по запросу.

## Задача

Материал есть, а времени на монтаж и озвучку нет. Нужен не «робот читает
текст», а разговор: вопрос — ответ, смена интонации, паузы.

## Пайплайн

```
тема / URL / PDF / текст
        │
        ▼
   извлечение и нормализация текста
        │
        ▼
   сценарий диалога (2 ведущих, 3 стиля)
        │
        ├── TTS: 5 голосов Silero
        ├── джингл (опционально)
        └── склейка ffmpeg
        │
        ▼
   подкаст + пост для Telegram/VK
```

## Решения

- **Fallback без LLM.** Без ключа пайплайн не падает, а собирает упрощённый
  сценарий — демо работает всегда.
- **Голоса офлайн.** Silero не требует сети и не считает символы.
- **Текст поста отдельно от аудио.** Один и тот же материал живёт в двух
  форматах, и второй не должен быть расшифровкой первого.

## Стек

Python · FastAPI · Silero TTS · ffmpeg · LLM API

## Что не публикуется

Промпты сценариев, ключи, собранные выпуски, голосовые образцы.

## Почему код закрыт

Внутри — рабочие конфиги, ключи, персональные данные и коммерческая часть.
Публиковать это нельзя, поэтому открыт только обзор: что делает система,
какие решения внутри и чему она научила.
